# آرشیو تخصصی مقالات و جستارهای بنیادین پارادایم جان‌گرایی

این مخزن دیجیتال شامل مجموعه‌ای از مقالات، تحلیل‌های فلسفی و جستارهای انتقادی پیرامون ادبیات ضدقدرت، آزادی‌خواهی، نقد ساختارهای اقتدارگرا و بنیان‌های «پارادایم جان‌گرایی» است. تمامی نوشته‌ها و آثار پژوهشی این بخش به قلم **نیما شهسواری** نگاشته شده و به عنوان بخشی از جنبش نشر آزاد و دسترسی عمومی به دانش، در این بستر قرار گرفته‌اند.
